## [01.04.000] - 2023-05-12
by _Andreas Ramböck_ and _Marcus Fiala_ of _SIGMATEK GmbH & Co KG_

### Added
- Added property to react on an event to stop the video
- Added LVD properties view tab assignment for all properties.

### Changed
- Removed property to set the video format
- Changed mute property to numerical and added the possibility to chose a datapoint.
- The border radius and width can now also be set as shorthand property
- Removed unnecessary polymer properties
- Removed dragged opacity and font property
- Changed the observer mechanism to be able to switch the video content via media item scheme.

### Bugfix
- Fixed an issue where the video was not stopped, when clicking with a mouse.
